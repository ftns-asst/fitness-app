# Покрытие функций HTML-макетами — 31 октября 2026

Этот аудит описывает версии 01–11. Следующая итерация 12 добавляет основные
экраны и сценарий тренировки: [сценарии и ограничения](12-prototype-flows.md).
Её упрощённая статистика — отдельный вариант композиции, а не отмена требований.

Итерация 13 перерабатывает навигацию и снимает дублирование: разбор проблем,
новая структура вкладок и обновлённая карта покрытия —
[переработка навигации](13-navigation-redesign.md).

Полного покрытия нет. Наличие кнопки, подписи или демонстрационного значения
не считается завершённым сценарием. Эта проверка относится к макетам, а не
к готовности приложения: часть запланированных функций ещё отсутствует в UI,
часть уже реализованных функций не отражена в старых HTML.

Проверены `fitness-assistant-frontend-design.md` (§2, §5),
`02-program-model.md` (§3, §5, UC-1…UC-13), `04-roadmap.md`,
`05-recommendations-catalog-today.md`, `07-programs-ui-spec.md`,
`08-exercises-sprint-plan.md`, `09-psmf-tracker-analysis.md` (FR-T1…T34),
HTML 01–10 и текущие контракты `Program_Stats_VM`, `Diary_VM`, `Program_Rules_VM`.
API и внутренние сервисы не являются самостоятельными экранами; их видимые
состояния (ошибка, офлайн, синхронизация) проверяются отдельно.

Обозначения: **есть** — показан конкретный интерфейс; **частично** — отсутствует
существенная часть сценария; **нет** — есть только описание в документации.
Даже «есть» не означает, что HTML связан с C++ или поддерживает весь бизнес-процесс.

## 4. Решения по дизайну

В 11 на главном экране добавлен мягкий пространственный переход акцентного
цвета в белую поверхность. Он не пульсирует и не двигается при прокрутке.
Текст и интерактивные элементы остаются контрастными; в тёмной теме переход
заканчивается тёмной поверхностью. Насыщенность можно проверить сменой акцента.

Аналитика раскрывается по задачам; нет одной длинной ленты всех показателей.
Сохраняются область, программа и период. У графика — единицы, даты, выбранное
значение и доступная текстовая таблица; нет будущих точек со значением 0.
Знаки/текст дублируют цвет. Анимации отключаются через prefers-reduced-motion.

Основание: [Apple — Charts](https://developer.apple.com/design/human-interface-guidelines/charts),
[Apple — Charting data](https://developer.apple.com/design/human-interface-guidelines/charting-data),
[Apple — Accessibility](https://developer.apple.com/design/human-interface-guidelines/accessibility).

## 5. Документационные расхождения и следующий приоритет

`07-programs-ui-spec.md` содержал два описания редактора: новая секция оказалась
в начале файла, старая осталась в §5.3. В этой правке они сведены к одной
актуальной секции. Исправлено устаревшее утверждение, что ProgramRulesPickerPage
отсутствует в коде. Старый README HTML описывал мастер с сохранением на последнем
шаге, хотя 09 уже использует раскрывающиеся карточки и постоянную кнопку.

Значки готовности в roadmap/09 местами отстают от текущего кода T1–T3;
не следует определять готовность приложения по наличию HTML или старому статусу.
§5.6 документа 07 и макет 06 описывают раннюю сводку; текущий Program_Stats_VM
уже предоставляет больше данных, включая тренды, весовую серию и карту изменений.
В этой работе продуктовая реализация функций не меняется.

Для следующего макета приоритет: несколько целей и серии → полная карта замеров
и сравнение графиков → запись/история тренировки (источник силовой аналитики) →
жизненный цикл программы → единый пакет сценариев входа, профиля, синхронизации
и переноса данных. Пробелы выше намеренно не отмечены как закрытые одной кнопкой.
